# Module 6 — Summative Assessment Bank
## Carpentry Joints & Assembly Techniques

**Delivery:** 25 randomized MCQs | **Bank:** 52 | **Pass:** 70% | **Maximum attempts:** 3 | **Prerequisite:** Module 6 Formative Assessment passed.

This bank emphasizes application, diagnosis, sequence and workplace judgement across Lessons 1–8.

1. A drawing specifies a housing joint but a carpenter prefers screws. Correct action? A Substitute B Follow specification or obtain approved change C Use both without approval D Remove shelf. **B**.
2. A joint is accurate individually but the finished frame racks. What must be checked? A Whole-assembly geometry B Paint C Tool brand D Timber name only. **A**.
3. Which factor is least appropriate as the sole basis for joint selection? A Load B Geometry C Personal habit D Material. **C**.
4. A joint closes only under extreme clamp pressure. Best response before glue? A Increase pressure B Diagnose fit C Add more adhesive D Nail it. **B**.
5. Why is short grain near a joint a concern? A It can create a weak local section B It improves all joints C It eliminates movement D It replaces fasteners. **A**.
6. A carpenter wants to change a specified joint to save time. What is required? A Nothing B Appropriate approval C More glue D Different pencil. **B**.

7. A screwed butt joint splits near the panel edge. Most professional response? A Add another screw beside split B Stop and review screw, pilot preparation and edge placement C Fill and ignore D Overdrive screw. **B**.
8. A dowelled butt joint stops 4 mm short of closing. Which is a plausible cause? A Hole depth/debris/misalignment B Correct geometry C Paint colour D Clamp label. **A**.
9. Which statement about biscuits is best? A Universal structural replacement B Joining/alignment system whose role depends on design C Only decorative D Cannot be used in boards. **B**.
10. Why should a butt-joint end be checked for square when square contact is specified? A Out-of-square ends can create gaps/misalignment B It changes species C It increases glue cure D It removes need for clamps. **A**.
11. A screw head is stripped during installation. Best action? A Keep driving B Stop and correct installation/fixing issue C Paint over it D Hit with hammer. **B**.
12. Why can end-grain bonding differ from long-grain bonding? A Wood structure/orientation affects bonding behaviour B End grain is metal C Adhesive ignores surfaces D There is no difference ever. **A**.

13. A cross-halving joint finishes with one face 2 mm proud. Likely check first? A Recess depth and stock thickness B Paint C Nail colour D Room lighting. **A**.
14. Saw cut crosses the shoulder line. Why is this serious? A It can create a gap/weak shoulder B It makes joint waterproof C It improves fit D It increases timber length. **A**.
15. A recess is loose after excessive paring. Best principle? A Glue always fixes it B Assess against acceptance criteria and repair/remake as approved C Add random packing D Ignore. **B**.
16. What reduces cumulative error in repeated set-out? A Consistent reference surfaces and verified setup B Measuring from random ends C Removing marks D Cutting before drawing. **A**.
17. A halving joint binds at one high point. Correct fitting? A Remove confirmed high spot gradually B Deepen entire recess C Force it D Add bolt. **A**.
18. Why is material removal in a halving joint a design consideration? A It reduces remaining section B It makes timber grow C It eliminates loads D It changes species. **A**.

19. Three shelf housings are to be routed. Best sequence? A Route all before checking B Test/verify first setup, then repeat C Remove fence D Estimate depth by sound. **B**.
20. A stopped housing accidentally runs through a visible edge. This is primarily: A Set-out/process nonconformance B Desired feature C Adhesive issue D Moisture test. **A**.
21. A housing is too tight for actual board thickness. What should be checked? A Actual stock thickness, set-out and cutter setup B Paint only C Supplier distance D Clamp colour. **A**.
22. Why use backing/support where appropriate at cutter exit? A Reduce breakout B Increase moisture C Replace guards D Increase groove depth. **A**.
23. A rebate varies in depth along its length. Likely concern? A Setup/control or workpiece support B Correct repeatability C Stronger joint automatically D No quality effect. **A**.
24. What determines housing depth in professional work? A Drawing/design and actual application B Deepest possible cut C One universal fraction D Carpenter mood. **A**.

25. A tenon enters easily but shoulders do not seat. Best action? A Diagnose shoulder, debris, cheek or mortise alignment B Add glue to gap C Increase clamp force immediately D Shorten random part. **A**.
26. Mortise and tenon were gauged from opposite nonmatching faces. Likely result? A Component offset B Automatic alignment C Stronger adhesive D No possible effect. **A**.
27. Which is the female part of the joint? A Tenon B Mortise C Shoulder D Cheek. **B**.
28. A haunch is present on the approved drawing. What should learner do? A Omit it B Produce specified form accurately C Replace with nail D Guess dimensions. **B**.
29. Why dry assemble a multi-joint frame? A Verify all joints and whole geometry together B Cure glue C Avoid measuring D Remove labels. **A**.
30. A mortise is accidentally oversized. Correct response? A Hide with glue B Assess approved repair/remake route C Make tenon random size without checking drawing D Add paint. **B**.
31. Which surface often controls visible closure between rail and stile? A Shoulder B Saw handle C Clamp bar D Pencil line only. **A**.

32. A dowel jig is 2 mm off its intended reference. What happens if used on 20 parts? A Error may be repeated 20 times B It self-corrects C Dowels change position automatically D No effect. **A**.
33. Mechanical connector drilling dimensions should be verified against: A Product/production specification B Memory only C Similar-looking connector D Fastener colour. **A**.
34. A cam fitting does not engage. Best first response? A Force it B Check drilling position/depth/orientation C Glue cam permanently D Enlarge every hole. **B**.
35. Biscuit-joined panel faces have a step. Likely cause to investigate? A Inconsistent registration/fence setting B Adhesive colour C Panel price D Clamp brand. **A**.
36. Why label mating components? A Prevent pairing/orientation errors B Increase strength C Change dimensions D Replace drawings. **A**.
37. A blind dowel hole contains debris and joint will not close. Correct action? A Clean/inspect according to process B Hammer harder C Shorten component D Add nail. **A**.

38. Which statement about adhesive is correct? A Product instructions control application/cure B Every wood adhesive has same cure C More glue fixes inaccurate joints D Adhesive replaces dry fitting. **A**.
39. Excessive clamping pressure bows a frame. What should be done? A Rebalance/reduce pressure and restore geometry while adjustable B Add pressure C Ignore until cured D Cut frame. **A**.
40. A carpenter selects a larger screw because “bigger is stronger.” What is wrong? A Selection must suit material/design and may cause splitting or penetration B Bigger is always correct C Screws have no dimensions D Only colour matters. **A**.
41. Which is a reason to use a washer where specified? A Distribute bearing/clamping load B Sharpen bolt C Change wood species D Replace nut. **A**.
42. A fastener for an exposed environment is selected only because it is shiny. Best judgement? A Inadequate—verify specified corrosion/service suitability B Always correct C Colour proves rating D Environment never matters. **A**.
43. A powered nailer safety mechanism is inconvenient. Correct action? A Defeat it B Keep safety system intact and follow training/manufacturer rules C Tape trigger D Point away only when loaded. **B**.
44. Adhesive has unknown product instructions. Best action? A Guess clamp time B Obtain correct product guidance before use C Use maximum pressure D Mix with another adhesive. **B**.

45. A rectangular frame has equal diagonals but wrong overall width. Is it acceptable? A Not necessarily; dimensions must also meet specification B Yes automatically C Only if painted D Diagonals replace all checks. **A**.
46. During clamping, diagonals change from equal to unequal. What does this show? A Clamp pressure/layout altered geometry B Timber became another species C Drawing changed D Glue removed dimensions. **A**.
47. Why use pads under clamp jaws? A Protect surfaces/distribute local pressure where needed B Increase screw length C Replace square D Make glue cure instantly. **A**.
48. A frame sits with one corner raised on a verified flat surface. What should be investigated? A Twist/assembly distortion B Paint C Dowel colour D Supplier invoice. **A**.
49. What should be prepared before adhesive is applied? A Clamps, tools, sequence and measurement plan B Only paint C Customer receipt D Offcuts only. **A**.
50. Several finished frames share the same diagonal error. Best quality response? A Investigate upstream setup/cut lengths/jig/clamping process B Repair each without investigation C Add more glue D Change finish. **A**.
51. When is the best time to correct assembly geometry? A While joints remain adjustable, before cure/final fixing B After delivery C After final paint only D Never. **A**.
52. Final joint inspection should compare the product against: A Drawing/specification and acceptance criteria B Personal preference only C Tool catalogue D Material price only. **A**.

## Summative Controls
- Randomly select 25 unique questions per attempt.
- Selection logic must provide broad coverage across all eight teaching lessons and include application/judgement items.
- Formative pass is required before access.
- Maximum 3 attempts; all attempts retained for audit.
- Score >=70% = pass for the Module 6 summative; below 70% = Not Yet Competent for that attempt.
- Feedback may identify the relevant lesson after submission; the live system must not expose correct answers before submission.
- Questions are derived from taught content and do not introduce untaught engineering capacities, proprietary dimensions or universal adhesive timings.
