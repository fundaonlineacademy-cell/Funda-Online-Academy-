# Module 10 — Summative Assessment Bank
## Applied Carpentry Practice & Workplace Readiness

**Bank size:** 52 MCQs  
**Delivery:** 25 questions randomly selected per attempt  
**Pass mark:** 70%  
**Maximum attempts:** 3  
**Prerequisite:** Passed Module 10 Formative Assessment  
**Purpose:** Integrated assessment of job interpretation, planning, costing, safe work planning, execution, quality control, handover, employability and entrepreneurship.

## Questions
**Q1.** A brief and current drawing disagree on overall width. Production should: A follow brief B follow drawing C stop affected work and obtain clarification D average values. **Answer: C.** Explanation: Conflicting controlled information must be resolved. Trace: L1.

**Q2.** Which is strongest evidence of scope? A Carpenter's assumption B Approved brief/drawing/specification C Old similar project D supplier advertisement. **Answer: B.** Trace: L1.

**Q3.** A finish is described only as “same as before” but the previous system cannot be identified. Best action? A choose any clear coat B clarify the required finish/system C leave unfinished D stain dark. **Answer: B.** Trace: L1.

**Q4.** Why identify service location when interpreting a brief? A It can affect material, fixing, finish and durability decisions B It determines employee salary C It replaces dimensions D It removes inspection. **Answer: A.** Trace: L1.

**Q5.** A customer asks for a dimension change after material has been cut. The carpenter should first: A hide existing work B assess effect and follow change approval process C continue old dimension without communication D change all components immediately. **Answer: B.** Trace: L1/L7.

**Q6.** Acceptance criteria are most useful when established: A before relevant production begins B only after complaint C after invoice D never. **Answer: A.** Trace: L1/L6.

**Q7.** Which sequence is generally most controlled for a cabinet? A finish → cut → drawing B verify information → plan → machine → dry fit/check → assemble → finish → inspect/handover C invoice → guess → install D assemble → measure. **Answer: B.** Trace: L2.

**Q8.** Why identify dependencies? A To understand which tasks/conditions must precede others B To increase paperwork only C To remove safety D To avoid material lists. **Answer: A.** Trace: L2.

**Q9.** Hardware needed in six weeks has an eight-week lead time. Best planning response? A ignore it B address procurement/approved alternatives early C finish job without hardware D blame supplier at handover. **Answer: B.** Trace: L2.

**Q10.** A site opening must be verified before final manufacture. It is best treated as: A irrelevant B a dependency/hold point C decoration D overhead. **Answer: B.** Trace: L2/L6.

**Q11.** Quality checks should be planned: A only at final handover B at relevant stages throughout production C only after customer complaint D only for expensive timber. **Answer: B.** Trace: L2/L6.

**Q12.** If site dimensions materially differ from approved drawings, the carpenter should: A force installation B clarify/revise affected information before continuing C trim everything randomly D ignore drawing. **Answer: B.** Trace: L2.

**Q13.** Four parts require 2.4 m net timber, but stock comes in longer fixed lengths. Purchasing quantity should be determined from: A exactly 2.4 m regardless of stock B actual stock sizes and cutting plan C a universal 20% rule D customer age. **Answer: B.** Trace: L3.

**Q14.** Which is a direct consumable in many carpentry jobs? A Sandpaper B Company logo C CV D customer signature. **Answer: A.** Trace: L3.

**Q15.** Which statement about waste allowance is correct? A One percentage fits every job B It should reflect actual material, stock, layout, process and quality conditions C Waste must always be zero D Double every order. **Answer: B.** Trace: L3.

**Q16.** A cutting plan improves costing because it: A helps translate component needs into realistic purchasing/yield B replaces dimensions C sets tax law D determines customer name. **Answer: A.** Trace: L3.

**Q17.** Which cost can be missed if only timber is priced? A Hardware, adhesives, abrasives and labour B drawing title C project colour only D none. **Answer: A.** Trace: L3.

**Q18.** A carpenter's original estimate was repeatedly lower than actual material use. Best improvement? A raise every quote randomly B compare estimate versus actual and investigate causes C stop recording costs D reduce quality. **Answer: B.** Trace: L3/L8.

**Q19.** A machine safety feature is defective. Correct response? A improvise B remove from use/report under procedure C wear gloves near rotating cutter and continue D ask client to accept risk. **Answer: B.** Trace: L4.

**Q20.** Which is a higher-quality risk response than relying only on PPE? A Use appropriate guarding/extraction/workholding and required PPE B remove guard C work faster D ignore dust. **Answer: A.** Trace: L4.

**Q21.** Before using a finishing chemical, the carpenter should consult relevant product information/SDS because: A all coatings are identical B hazards and controls can be product-specific C SDS gives cabinet dimensions D it calculates labour. **Answer: B.** Trace: L4.

**Q22.** A wall's construction is unknown and the cabinet will carry significant load. Best response? A use longest available screw B verify substrate and approved fixing requirements C use more random screws D omit fixings. **Answer: B.** Trace: L4.

**Q23.** A large sheet must be moved through a narrow occupied corridor. Good planning includes: A clear route and suitable handling/control B carrying blind C dragging over floor D throwing it. **Answer: A.** Trace: L4/L7.

**Q24.** Stop-work authority is most important when: A essential information/control needed for safe compliant work is absent B lunch is near C material is attractive D customer is quiet. **Answer: A.** Trace: L4.

**Q25.** Why verify a first-off component? A To prevent systematic error across repeated components B To avoid drawings C To increase offcuts D To replace final inspection. **Answer: A.** Trace: L5.

**Q26.** Ten shelf sides are to be cut. The first is wrong due to stop setup. Best action? A cut remaining nine identically B correct setup and verify new first-off C alter specification D discard drawing. **Answer: B.** Trace: L5.

**Q27.** Consistent reference faces/edges help control: A measurement and machining relationships B customer payments C tax D delivery address. **Answer: A.** Trace: L5.

**Q28.** During dry fit, an assembly is out of square. Best action? A permanently fix it B diagnose/correct before irreversible assembly C cover with paint D hide with back panel. **Answer: B.** Trace: L5/L6.

**Q29.** Why identify matched components? A To preserve intended orientation/grain/hardware relationships B To increase price C To avoid labels D To change scope. **Answer: A.** Trace: L5.

**Q30.** An adhesive requires specific preparation and cure conditions. The carpenter should follow: A universal workshop habit B relevant manufacturer/specification requirements C shortest online comment D guess. **Answer: B.** Trace: L5.

**Q31.** Incoming board is swollen and delaminating. Best quality action? A machine it quickly B isolate/report and assess against requirements C hide damaged edge D use for critical part automatically. **Answer: B.** Trace: L6.

**Q32.** A tolerance should be: A invented by carpenter B taken from applicable controlled requirement where specified C always ±1 mm D ignored. **Answer: B.** Trace: L6.

**Q33.** A defect is discovered after machining but before assembly. Best general approach? A identify, contain, determine authorised correction/replacement and verify B hide it C assemble anyway D blame timber. **Answer: A.** Trace: L6.

**Q34.** Why inspect surfaces before coating? A Surface defects/contamination can affect final finish and become harder to correct B coating fixes all defects C to waste time D only for photos. **Answer: A.** Trace: L6.

**Q35.** Reworked work should be: A automatically accepted B re-inspected against affected requirement C painted immediately D undocumented. **Answer: B.** Trace: L6.

**Q36.** A hold point primarily prevents: A work from continuing before required verification/approval B measuring C customer contact D tool cleaning. **Answer: A.** Trace: L6.

**Q37.** A client requests two extra shelves during installation. Best response? A perform without record B document/evaluate as variation according to process C remove existing shelves D refuse to speak. **Answer: B.** Trace: L7.

**Q38.** A professional handover should normally include: A final inspection and relevant operation/care information B hidden defects C unsupported performance claims D discarded records. **Answer: A.** Trace: L7.

**Q39.** A finish manufacturer states a cure period before heavy use. The carpenter should: A invent shorter time B communicate the applicable manufacturer requirement C say all finishes cure overnight D omit aftercare. **Answer: B.** Trace: L7.

**Q40.** A customer reports a drawer binding. First professional response? A blame customer B record issue, inspect and compare against requirements C delete contact D promise full replacement before inspection. **Answer: B.** Trace: L7.

**Q41.** Why protect floors and nearby finishes during installation? A Customer property/site condition is part of professional delivery B To increase material waste C It replaces PPE D No reason. **Answer: A.** Trace: L7.

**Q42.** A handover snag should be: A concealed B recorded with agreed responsibility/follow-up C ignored D invoiced without explanation. **Answer: B.** Trace: L7.

**Q43.** Which portfolio is most credible? A Only polished final images B Evidence showing planning, process, checks and completed work C copied projects D unsupported titles. **Answer: B.** Trace: L8.

**Q44.** A course graduate who has not completed a statutory trade test should: A claim trade-tested status B describe the actual credential accurately C invent registration D omit all training. **Answer: B.** Trace: L8.

**Q45.** Which behaviour strongly supports employability? A Hiding mistakes B Reliability, safe work, communication and responsibility C ignoring instructions D poor housekeeping. **Answer: B.** Trace: L8.

**Q46.** Before accepting a small paid job, a carpenter should first understand: A scope, site conditions, quantities, costs and risks B only desired profit C only colour D only customer's phone model. **Answer: A.** Trace: L8.

**Q47.** A job includes an electrical alteration beyond the carpenter's competence. Best action? A perform it anyway B refer/escalate to appropriately competent/authorised person C conceal wiring D guess. **Answer: B.** Trace: L8.

**Q48.** A pricing error is discovered after agreement. Which response is unacceptable? A follow applicable commercial/change process B silently reduce specified material quality to recover margin C discuss authorised options D improve future costing. **Answer: B.** Trace: L8.

**Q49.** Which is a useful continuous-development goal? A “Get better someday” B “Complete supervised practice and evidence on three accurate mortise-and-tenon joints by a set review date” C “Never ask feedback” D “Buy tools only.” **Answer: B.** Trace: L8.

**Q50.** Why review waste after every project? A To identify process improvements and improve future costing B To change completed drawing C To avoid recycling D To increase defects. **Answer: A.** Trace: L3/L8.

**Q51.** An integrated professional response to a project is best described as: A fastest cutting only B interpret → plan → risk-control → execute → inspect → communicate → hand over → review C buy tools → invoice D finish → measure. **Answer: B.** Explanation: Workplace readiness integrates the entire course workflow. Trace: L1–L8.

**Q52.** The strongest evidence that a carpenter is workplace-ready is: A confidence alone B consistent, safe, specification-based work supported by records, quality checks and professional conduct C owning many tools D lowest price. **Answer: B.** Trace: L1–L8.
