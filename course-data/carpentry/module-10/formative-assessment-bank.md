# Module 10 — Formative Assessment Bank
## Applied Carpentry Practice & Workplace Readiness

**Bank size:** 32 MCQs  
**Delivery:** 15 questions randomly selected per attempt  
**Pass mark:** 70%  
**Maximum attempts:** 3  
**Progression:** A pass is required before the Module 10 Summative Assessment unlocks.  
**Coverage:** 4 questions per teaching lesson.

### Lesson 1 — Interpreting a Client or Workplace Brief
**Q1.** A drawing gives cabinet width but the client message gives a different width. What is the best first action? A Use the larger value B Use the drawing automatically C Clarify the conflict before affected work proceeds D Average them. **Answer: C.** Explanation: Conflicting controlled information must be resolved, not guessed. Trace: L1.

**Q2.** Which item is an assumption rather than a confirmed requirement? A Material named in approved specification B Dimension on current approved drawing C Carpenter believes the client probably wants satin finish D Hardware listed in schedule. **Answer: C.** Explanation: Belief without supporting approved information is an assumption. Trace: L1.

**Q3.** Why identify acceptance criteria before manufacture? A To remove inspection B To align production and final judgement with the same requirements C To permit substitutions D To avoid drawings. **Answer: B.** Explanation: Quality must be designed and checked against known requirements. Trace: L1.

**Q4.** A client verbally changes a specified material. The change affects price and durability. Best response? A Substitute immediately B Record and obtain required approval before affected work C Ignore client D Mix materials. **Answer: B.** Explanation: Significant changes require controlled variation/revision. Trace: L1.

### Lesson 2 — Planning an End-to-End Carpentry Job
**Q5.** Which is a dependency? A Final finish colour B Site measurement that must be confirmed before final cutting C Brand logo D Invoice number. **Answer: B.** Explanation: A dependency is a prerequisite for a later activity. Trace: L2.

**Q6.** Why should dry-fit inspection occur before final adhesive where appropriate? A Adhesive is expensive B Fit and geometry can be corrected before becoming difficult to reverse C To eliminate measurement D To increase waste. **Answer: B.** Trace: L2.

**Q7.** A specified hinge has a long lead time. When should this normally be identified? A At handover B During resource/planning review C After doors are installed D Never. **Answer: B.** Explanation: Procurement constraints should be identified before they disrupt production. Trace: L2.

**Q8.** A contingency plan should allow a carpenter to silently replace unavailable specified material. A True B False C Only for expensive material D Only on Fridays. **Answer: B.** Explanation: Substitution still requires appropriate approval. Trace: L2.

### Lesson 3 — Basic Costing, Material Quantities & Waste Estimation
**Q9.** Quantity take-off should primarily come from: A guesswork B controlled drawings/cutting information C competitor advertising D final invoice. **Answer: B.** Trace: L3.

**Q10.** Why can purchasing quantity exceed net component quantity? A Because all waste is mandatory B Stock sizes, cutting layout, actual process requirements and suitable allowances affect purchasing C Because drawings are irrelevant D To increase price. **Answer: B.** Trace: L3.

**Q11.** Which approach to waste allowance is strongest? A Always add 10% B Always add 20% C Base it on actual material, stock format, cutting plan, defects and process D Never allow waste. **Answer: C.** Explanation: There is no universal percentage for every job. Trace: L3.

**Q12.** Why compare estimated cost with actual cost after completion? A To improve future estimating and waste control B To change completed dimensions C To avoid records D To remove labour. **Answer: A.** Trace: L3.

### Lesson 4 — Safe Work Method & Risk Planning
**Q13.** A circular saw's required guard is defective. Best action? A Wear extra PPE and continue B Remove tool from use/report according to procedure C Cut faster D Ask customer. **Answer: B.** Explanation: PPE does not compensate for defective required guarding. Trace: L4.

**Q14.** Before drilling into an unfamiliar installation substrate, the carpenter should first: A choose longest screw B verify substrate, relevant concealed-service risk and approved fixing method C drill trial holes everywhere D use glue only. **Answer: B.** Trace: L4.

**Q15.** An SDS is especially useful for: A choosing timber dimensions B chemical product hazard/handling information C measuring square D pricing labour. **Answer: B.** Trace: L4.

**Q16.** Which is a valid stop-work trigger? A Essential safety control is absent B Customer says hello C Tool is clean D Drawing is clear. **Answer: A.** Trace: L4.

### Lesson 5 — Executing & Sequencing a Practical Project
**Q17.** A first-off component is outside the controlled dimension. What should happen before batch production? A Continue and correct later B Correct cause/setup and verify a compliant first-off C Change drawing D Hide component. **Answer: B.** Trace: L5.

**Q18.** Why maintain reference faces/edges? A Decoration B To maintain consistent measurement and machining relationships C To increase material use D To replace drawings. **Answer: B.** Trace: L5.

**Q19.** A joint does not fit during dry assembly. Best response? A Force it B Identify cause and make controlled correction C Apply more finish D Ignore it. **Answer: B.** Trace: L5.

**Q20.** Protecting components between operations is part of quality control. A True B False C Only for hardwood D Only after handover. **Answer: A.** Trace: L5.

### Lesson 6 — Quality Control During Project Execution
**Q21.** Quality inspection should compare work mainly against: A personal preference B controlled requirements C fastest competitor D random sample online. **Answer: B.** Trace: L6.

**Q22.** When is a strong time to check cabinet squareness? A Only after handover B During dry/final assembly before geometry is irreversibly locked C Never D After invoicing. **Answer: B.** Trace: L6.

**Q23.** After authorised rework, what should occur? A No further check B Re-inspect affected requirement C Change specification D Hide record. **Answer: B.** Trace: L6.

**Q24.** What is a hold point? A Lunch break B Stage where work does not proceed until required verification/approval occurs C Storage shelf D Customer complaint. **Answer: B.** Trace: L6.

### Lesson 7 — Customer Communication, Handover & Aftercare
**Q25.** A customer requests an extra shelf outside agreed scope. Best response? A Always do it without discussion B Follow variation/scope approval process C Refuse all changes D Remove existing shelf. **Answer: B.** Trace: L7.

**Q26.** Before handover, the carpenter should: A rely on customer to find defects B conduct final inspection against approved scope/requirements C hide snags D discard records. **Answer: B.** Trace: L7.

**Q27.** Aftercare instructions for a coating should come from: A guessed universal rule B relevant manufacturer/product and approved job information C neighbour's opinion D unrelated product. **Answer: B.** Trace: L7.

**Q28.** A complaint is best initially handled by: A immediate blame B listening, recording facts and comparing issue with requirements C deleting messages D promising anything. **Answer: B.** Trace: L7.

### Lesson 8 — Employability, Portfolio, Entrepreneurship & Continuous Development
**Q29.** Which portfolio evidence is strongest? A Only one final photo B Process evidence linked to drawings, planning, checks and final outcome C Unverified claims D Another person's project. **Answer: B.** Trace: L8.

**Q30.** A graduate should describe credentials: A more impressively than earned B exactly and truthfully C as a trade test even when not one D without evidence. **Answer: B.** Trace: L8.

**Q31.** Work requiring capability or authorisation beyond the carpenter's competence should normally be: A guessed B referred/escalated to an appropriately competent/authorised person C hidden D accepted regardless. **Answer: B.** Trace: L8.

**Q32.** Which habit best supports continuous development? A Never review completed work B Record lessons, seek feedback and set specific skill goals C Avoid manufacturer instructions D Repeat errors. **Answer: B.** Trace: L8.
