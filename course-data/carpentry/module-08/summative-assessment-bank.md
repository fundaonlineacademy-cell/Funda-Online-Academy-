# Carpentry Fundamentals — Module 8 Summative Assessment Bank
## Surface Preparation, Finishing & Protection

**Delivery configuration:** 52-question bank; platform randomly selects 25 questions per attempt; A–D multiple choice; pass mark 70%; maximum 3 attempts; prerequisite: passed Module 8 Formative Assessment. Questions assess integrated understanding, application, diagnosis and workplace judgement across Lessons 1–8.

1. A cabinet door for clear finishing has glue residue and cross-grain scratches. Best sequence? A Apply clear coat then sand B Assess, remove contamination, progressively prepare scratches, clean and reinspect C Paint it D Fill the entire face. **Answer: B.** Explanation: preparation defects should be corrected before transparent finishing. [L1]
2. Which defect most clearly requires referral rather than cosmetic finishing? A Light pencil mark B Severe board delamination C Loose dust D Minor sanding mark. **Answer: B.** Explanation: delamination is a substrate failure. [L1]
3. Why protect reference edges during surface preparation? A They may control dimensions and fitting accuracy B They improve stain colour C They make paint dry D They contain solvent. **Answer: A.** [L1]
4. A worker sees a dark greasy patch. Best first response? A Sand aggressively B Identify contamination and use an approved compatible cleaning process C Add varnish D Wet it. **Answer: B.** [L1]
5. What is the purpose of reinspecting after preparation? A Confirm readiness and that preparation has not created new defects B Increase moisture C Avoid cleaning D Replace specification. **Answer: A.** [L1]
6. Which principle best describes abrasive starting selection? A Coarsest possible B Least aggressive stage that efficiently corrects existing condition C Finest possible always D Same grit for all jobs. **Answer: B.** [L2]
7. A veneer face is being sanded. Primary additional concern? A Cutting through the thin decorative layer B Veneer cannot hold finish C It has no grain D It cannot produce dust. **Answer: A.** [L2]
8. Deep scratches remain after jumping from a coarse to very fine abrasive. Most likely issue? A Progression skipped a useful intermediate stage B Timber changed species C Clear finish is too dark D The board is too long. **Answer: A.** [L2]
9. Why use a sanding block on a flat hand-sanded surface? A Help distribute pressure and preserve flatness B Increase moisture C Replace inspection D Make filler cure. **Answer: A.** [L2]
10. What determines when to advance to the next abrasive? A Time alone B Previous significant marks have been adequately removed and geometry remains correct C Number of workers D Colour of abrasive. **Answer: B.** [L2]
11. Why should MDF sanding include appropriate dust controls? A It can generate fine dust B MDF contains no fibres C Dust improves coatings D Sanding creates water. **Answer: A.** [L2]
12. A small nail hole in a paint-grade panel is stable. Appropriate response? A Use compatible filler according to instructions B Replace entire building C Ignore it D Apply clear stain first. **Answer: A.** [L3]
13. A split is actively opening at a joint. Appropriate action? A Fill cosmetically B Correct/refer underlying structural or assembly problem C Wax it D Add topcoat. **Answer: B.** [L3]
14. Why can overfilling be inefficient? A It creates unnecessary material removal and may damage adjacent surfaces B It prevents all cure C It always changes colour to black D It increases strength. **Answer: A.** [L3]
15. What should determine repair-material maximum thickness? A Guesswork B Manufacturer/system requirements C Same value for every filler D Timber price. **Answer: B.** [L3]
16. A transparent finish is specified. Which repair issue deserves special attention? A Filler colour/absorption mismatch B Screwdriver colour C Workshop clock D Shelf count. **Answer: A.** [L3]
17. A repair feels dry on top but instructions specify longer before sanding. What should happen? A Sand now B Wait for the specified readiness condition C Apply topcoat D Wet it. **Answer: B.** [L3]
18. Which statement is correct? A All stains provide complete protection B Colouring and protection functions must be verified for the actual system C Dye cannot colour timber D Clear topcoats always remove stain. **Answer: B.** [L4]
19. Why can end grain become darker with stain? A Different absorption behaviour B It has paint inside C It is always rotten D It is synthetic. **Answer: A.** [L4]
20. A stain sample looks different from a colour chart. Best explanation? A Actual timber, preparation and system affect appearance B Charts always guarantee exact results C Timber has no colour D The sample is automatically wrong. **Answer: A.** [L4]
21. What is the best approval sample? A Representative material prepared and finished using intended system stages B Random unrelated species C Bare timber only when topcoat changes appearance D Printed photo only. **Answer: A.** [L4]
22. Glue blocks stain uptake beside a joint. The pale patch demonstrates: A Preparation affects colour consistency B Stain strengthens glue C Grain disappears D Topcoat is unnecessary. **Answer: A.** [L4]
23. Why keep colour/product identification records where required? A Traceability and repeatability B To increase dust C To replace inspection D To avoid drying. **Answer: A.** [L4]
24. An exterior component needs a clear finish. What should the worker do? A Assume any varnish is suitable B Verify product/system is specified for the exposure and substrate C Use wax automatically D Select by smell. **Answer: B.** [L5]
25. What is a film-forming finish? A A system that forms a continuous coating layer on the surface B Any sandpaper C Timber moisture D A joint. **Answer: A.** [L5]
26. Why may a sealer be used? A As a specified system stage to control/prepare substrate behaviour B To repair structural splits C To measure timber D To sharpen tools. **Answer: A.** [L5]
27. A first clear coat has dust nibs. Best action? A Immediately flood with another coat B Allow appropriate readiness, prepare as specified, clean and continue C Ignore product instructions D Scrape wet film with a chisel. **Answer: B.** [L5]
28. Why is cure important before service? A Final properties may continue developing after touch dryness B Cure changes timber species C Cure eliminates all scratches D Cure is the same as sanding. **Answer: A.** [L5]
29. Which statement about oils/waxes/varnishes is correct? A Their exact protection and use suitability must be verified by product B All are identical C All are exterior waterproof D None need safety controls. **Answer: A.** [L5]
30. Old paint is flaking near a door bottom. First professional approach? A Add new paint B Diagnose substrate/coating condition and remove/prepare unsound material appropriately C Add wax D Hide it with hardware. **Answer: B.** [L6]
31. Why feather an old coating edge where required? A Create a smooth transition into the repaired area B Increase moisture C Make paint darker D Change timber grade. **Answer: A.** [L6]
32. Which is true of modern paint systems? A Every system requires separate primer, undercoat and topcoat B Product systems vary and may combine functions C Primer is always optional D Topcoat replaces preparation. **Answer: B.** [L6]
33. Why prime bare repaired areas when specified? A To provide the required base/function before subsequent coats B To sharpen sandpaper C To hide loose timber structurally D To eliminate drying. **Answer: A.** [L6]
34. A worker applies twice the specified wet film believing thicker is stronger. Main issue? A Excess thickness can create film/drying defects B It always doubles durability C It removes contamination D It improves every product. **Answer: A.** [L6]
35. Existing coating identity is uncertain. Best action? A Use approved compatibility/testing or referral procedure B Apply strongest solvent C Ignore it D Add oil. **Answer: A.** [L6]
36. Which application method usually introduces atomised mist/overspray controls? A Spray B Steel rule C Chisel D Clamp. **Answer: A.** [L7]
37. What should determine spray pressure/nozzle setup? A Equipment/product requirements and competent procedure B Maximum possible pressure C Worker preference only D Timber length. **Answer: A.** [L7]
38. Why can poor ventilation be dangerous? A Hazardous vapours/mist may accumulate depending on product B It makes timber hardwood C It eliminates coating D It sharpens tools. **Answer: A.** [L7]
39. Why can excessive airflow also be undesirable? A It can carry dust and affect coating flow/drying B Air always cures perfectly C It removes all defects D It prevents adhesion universally. **Answer: A.** [L7]
40. A product specifies a maximum recoat window and it has passed. Best response? A Follow the specified preparation before recoating B Ignore the window C Double the coat D Heat randomly. **Answer: A.** [L7]
41. A finished panel is stacked face-to-face while still vulnerable and develops pressure marks. Which process failed? A Post-application handling/protection B Measuring C Joint selection D Timber grading. **Answer: A.** [L7]
42. Why should specialised spray work require authorisation/competence? A Equipment and coating hazards require controlled operation B Spray is decorative only C It uses no chemicals D It cannot produce fire hazards. **Answer: A.** [L7]
43. A coating has a downward thick flow mark. Most likely defect name? A Run/sag B Cup C Bow D Wane. **Answer: A.** [L8]
44. Small raised particles appear in a clear coat. Likely description? A Dust nibs B Mortises C Checks D Kerfs. **Answer: A.** [L8]
45. Why should peeling be investigated before recoating? A Recoating without correcting cause can repeat failure B Peeling always improves adhesion C It changes colour only D It is normal curing. **Answer: A.** [L8]
46. What is a miss? A Area lacking required coating coverage B A timber knot C A clamp D A measurement error only. **Answer: A.** [L8]
47. When should a defective film be sanded? A Whenever visible B When the product/system has reached the appropriate condition for the approved repair C While wet in all cases D Before coating. **Answer: B.** [L8]
48. Why use padded supports for finished components? A Reduce scratching/printing and edge damage B Increase moisture C Improve stain absorption D Change dimensions. **Answer: A.** [L8]
49. What should determine cleaning products given to the customer? A Coating manufacturer's approved care guidance B Strongest household solvent C Any abrasive cleaner D Water for every finish. **Answer: A.** [L8]
50. Repeated dust nibs occur on many jobs. Best quality-control response? A Investigate finishing-area dust/process controls B Blame timber species automatically C Add thicker coats D Stop inspecting. **Answer: A.** [L8]
51. During installation a finished face is scratched by a drill. Best response? A Hide with random marker B Assess damage and use approved compatible repair/touch-up process C Ignore it D Apply filler over wet coating. **Answer: B.** [L8]
52. Which sequence best represents professional finishing quality control? A Coat → hide defects → deliver B Assess → prepare → apply compatible system → respect drying/cure → inspect → correct appropriately → protect → hand over C Sand everything coarsely → paint D Stain → measure → cut. **Answer: B.** Explanation: quality is controlled throughout the finishing workflow.
