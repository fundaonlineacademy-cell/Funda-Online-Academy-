## Question Bank

### Lesson 1 — Hand Tool Categories & Correct Selection

**Q1.** A learner must trim a small amount from the edge of a timber component while maintaining a straight, controlled surface. Which approach best demonstrates correct tool selection?  
A. Select the heaviest striking tool available  
B. Select a suitable plane after checking the task, timber and required finish  
C. Use any sharp tool because all cutting tools perform the same function  
D. Use a screwdriver to scrape the edge  
**Correct answer:** B  
**Explanation:** Professional tool selection begins with the operation, material, required accuracy and finish, followed by selection and inspection of the appropriate tool.  
**Traceability:** Lesson 1

**Q2.** Why is using a hand tool outside its intended purpose poor practice?  
A. It only makes the job slower  
B. It can damage the tool or workpiece and introduce avoidable safety and quality risks  
C. It is acceptable whenever the worker is experienced  
D. It matters only for electrical tools  
**Correct answer:** B  
**Explanation:** Improvised use can overload or damage a tool, reduce control and create defects or injury risks.  
**Traceability:** Lesson 1

**Q3.** A carpenter finds two tools that could perform a task. What should guide the final selection?  
A. Colour of the handle  
B. Which tool is closest to the bench  
C. Suitability for the material, operation, access, accuracy and required finish  
D. Which tool requires the most force  
**Correct answer:** C  
**Explanation:** Tool selection is task-specific and should support safe control and the specified quality outcome.  
**Traceability:** Lesson 1

**Q4.** During a pre-use check, a hand tool has a loose handle. What is the best response?  
A. Use it carefully for one final operation  
B. Ask another learner to hold the handle  
C. Remove it from use and follow the workplace reporting or repair procedure  
D. Increase grip pressure  
**Correct answer:** C  
**Explanation:** A loose handle is a defect that may cause loss of control. Defective tools should not remain in service until correctly addressed.  
**Traceability:** Lesson 1

**Q5.** Why should a carpenter understand tool categories rather than memorise tool names only?  
A. Categories help connect tool function with the operation that must be performed  
B. Categories eliminate the need for inspection  
C. Every tool in a category can be used interchangeably  
D. Categories determine the price of a tool  
**Correct answer:** A  
**Explanation:** Understanding function helps the worker make reasoned selections instead of treating tools as interchangeable objects.  
**Traceability:** Lesson 1

**Q6.** Which sequence best represents professional hand-tool practice?  
A. Pick tool → start work → inspect if a problem appears  
B. Understand task → select suitable tool → inspect tool/workpiece → secure work → use correctly → inspect result → care for/store tool  
C. Secure work → choose any tool → apply maximum force  
D. Start work → change tools repeatedly until one works  
**Correct answer:** B  
**Explanation:** Safe, accurate work is a planned process from selection through inspection, use, quality checking and storage.  
**Traceability:** Lesson 1

### Lesson 2 — Measuring & Marking Hand Tools

**Q7.** Why is a reference face established before marking several related dimensions?  
A. To make pencil lines darker  
B. To provide a consistent datum from which measurements and checks can be taken  
C. To reduce the need to read dimensions  
D. To identify the waste bin  
**Correct answer:** B  
**Explanation:** A consistent reference reduces cumulative errors and helps related faces and dimensions remain geometrically coordinated.  
**Traceability:** Lesson 2

**Q8.** A component is repeatedly measured from different rough ends and the marks do not agree. What is the most likely process problem?  
A. Too many clamps  
B. Lack of a consistent reference or datum  
C. The pencil is too short  
D. The timber is necessarily defective  
**Correct answer:** B  
**Explanation:** Switching reference points can compound error. Establishing and using consistent reference surfaces improves repeatability.  
**Traceability:** Lesson 2

**Q9.** What is the main purpose of a try square during marking out?  
A. Measuring moisture content  
B. Marking and checking a right angle relative to a suitable reference edge or face  
C. Cutting a kerf  
D. Holding two boards together  
**Correct answer:** B  
**Explanation:** A try square supports accurate 90-degree marking and checking when used against a reliable reference surface.  
**Traceability:** Lesson 2

**Q10.** A marking gauge is most useful when a line must be:  
A. parallel to a reference edge at a controlled offset  
B. drawn freehand around a curve  
C. measured vertically from the floor  
D. made with a hammer  
**Correct answer:** A  
**Explanation:** A marking gauge registers against an edge and marks a consistent parallel line.  
**Traceability:** Lesson 2

**Q11.** What should a worker do before trusting a measuring or marking tool for precision work?  
A. Assume it is accurate because it is metal  
B. Check its condition, cleanliness, readability and suitability for the required operation  
C. Lubricate every measuring surface heavily  
D. Compare its colour with another tool  
**Correct answer:** B  
**Explanation:** Damage, dirt, worn graduations or unsuitable tools can produce inaccurate work.  
**Traceability:** Lesson 2

**Q12.** A learner has marked four identical rails individually from the previous rail instead of from the drawing/reference dimension. What risk increases?  
A. Cumulative dimensional error  
B. Electrical shock  
C. Saw tooth damage  
D. Corrosion of clamps  
**Correct answer:** A  
**Explanation:** Successive transfer of dimensions can accumulate small errors. Repeated components should be controlled from reliable dimensions, references or approved patterns.  
**Traceability:** Lesson 2

### Lesson 3 — Saws & Manual Cutting Techniques

**Q13.** A board must be shortened across the direction of its grain. What type of operation is required?  
A. Rip cut  
B. Crosscut  
C. Paring cut  
D. Planing cut  
**Correct answer:** B  
**Explanation:** A crosscut runs across the grain; a rip cut generally follows the grain direction.  
**Traceability:** Lesson 3

**Q14.** Why should the saw kerf normally be positioned on the waste side of an accurately marked line?  
A. To preserve the required finished dimension  
B. To increase the thickness of the blade  
C. To avoid securing the workpiece  
D. To make the saw cut faster  
**Correct answer:** A  
**Explanation:** The blade removes material equal to its kerf. Planning the kerf on the waste side helps retain the specified component size.  
**Traceability:** Lesson 3

**Q15.** A long offcut begins to sag and the saw starts binding. What is the best response?  
A. Force the saw through quickly  
B. Twist the blade to widen the kerf  
C. Stop and correct the workpiece/offcut support before continuing  
D. Strike the saw with a mallet  
**Correct answer:** C  
**Explanation:** Poor support can close the kerf, trap the blade and cause loss of control or breakout.  
**Traceability:** Lesson 3

**Q16.** Which practice gives the best chance of starting a hand-saw cut accurately?  
A. Begin with maximum force  
B. Establish the kerf with controlled light strokes while observing the marked line  
C. Hold the workpiece by hand near the cutting line  
D. Start several millimetres inside the required component  
**Correct answer:** B  
**Explanation:** A controlled start establishes the saw path before full strokes are used.  
**Traceability:** Lesson 3

**Q17.** The cut follows the top marked line but emerges off the line on the underside. What does this indicate?  
A. The saw was necessarily blunt  
B. Blade alignment through the thickness was not adequately controlled  
C. The timber must be too dry  
D. The waste side was too large  
**Correct answer:** B  
**Explanation:** Accurate sawing requires monitoring more than the top line; the blade must remain correctly aligned through the workpiece thickness.  
**Traceability:** Lesson 3

**Q18.** What should happen as a hand-saw cut approaches completion?  
A. Increase force sharply  
B. Reduce control because the line has already been established  
C. Maintain control, support the offcut and reduce force where necessary to limit breakout  
D. Release the workholding before the cut separates  
**Correct answer:** C  
**Explanation:** Supporting the separating pieces and moderating force helps prevent splintering and uncontrolled movement.  
**Traceability:** Lesson 3

**Q19.** A saw repeatedly wanders despite a clear line. Which response is most professional?  
A. Keep forcing the saw and correct everything with filler  
B. Stop and diagnose tool condition, starting technique, workholding, body position and grain before continuing  
C. Remove the line so it is less distracting  
D. Use a hammer on the blade  
**Correct answer:** B  
**Explanation:** Quality problems should be diagnosed at their source rather than hidden after unnecessary material removal.  
**Traceability:** Lesson 3

### Lesson 4 — Chisels: Chopping, Paring & Controlled Cutting

**Q20.** Which statement best distinguishes chopping from paring with a chisel?  
A. Chopping generally removes waste using controlled impact where appropriate; paring uses controlled cutting pressure for finer trimming  
B. Paring always requires the heaviest mallet  
C. Chopping is performed only on metal  
D. They are identical operations  
**Correct answer:** A  
**Explanation:** Chopping and paring use different levels and methods of force and are selected according to the stage and precision of the cut.  
**Traceability:** Lesson 4

**Q21.** Why should a chisel not be used as an improvised pry bar?  
A. It makes the handle cleaner  
B. Side-loading can damage the edge or tool and cause sudden loss of control  
C. It improves sharpening  
D. It prevents timber movement  
**Correct answer:** B  
**Explanation:** Chisels are precision cutting tools. Improvised levering can damage them and create an unsafe, uncontrolled release.  
**Traceability:** Lesson 4

**Q22.** When paring near a final marked line, the best general approach is to:  
A. remove all remaining material in one heavy cut  
B. work progressively with controlled cuts while protecting the reference line and checking the surface  
C. cut toward the supporting hand  
D. ignore grain direction  
**Correct answer:** B  
**Explanation:** Progressive removal gives better control and reduces the risk of overshooting the final dimension or splitting the workpiece.  
**Traceability:** Lesson 4

**Q23.** Why must grain direction be considered during chisel work?  
A. Timber can split or tear beyond the intended cut if the fibres are unsupported or the cut follows the grain unpredictably  
B. Grain direction determines the colour of the handle  
C. Grain direction only matters during painting  
D. It eliminates the need for workholding  
**Correct answer:** A  
**Explanation:** Wood fibres can split ahead of a chisel. Reading the grain and controlling cut depth helps prevent breakout.  
**Traceability:** Lesson 4

**Q24.** A chisel handle is cracked before a chopping operation. What should the learner do?  
A. Wrap it in paper and continue  
B. Use lighter blows only  
C. Remove it from use and follow the authorised repair/reporting process  
D. Hold the crack closed while striking  
**Correct answer:** C  
**Explanation:** A cracked handle may fail under impact and should not be treated as serviceable.  
**Traceability:** Lesson 4

**Q25.** What is the safest general rule for the supporting hand during controlled chisel work?  
A. Place it in front of the cutting edge to guide the chisel  
B. Keep it out of the projected cutting path and use secure workholding  
C. Hold the waste directly under the edge  
D. Use the hand instead of a clamp whenever possible  
**Correct answer:** B  
**Explanation:** Hands and body should be kept out of the cutting path, with the workpiece held securely by appropriate workholding.  
**Traceability:** Lesson 4

**Q26.** A housing is almost at its final depth. What is the best quality-control approach?  
A. Continue heavy chopping until the line disappears  
B. Change to controlled fine cuts and check depth, flatness and reference lines frequently  
C. Remove the workholding and finish freehand  
D. Use a screwdriver to scrape the base  
**Correct answer:** B  
**Explanation:** Final fitting requires smaller controlled cuts and frequent checking to avoid removing too much material.  
**Traceability:** Lesson 4

### Lesson 5 — Planes: Surface & Edge Preparation

**Q27.** What is the primary function of a hand plane in basic carpentry?  
A. Driving nails  
B. Removing controlled shavings to prepare, flatten, straighten, size or smooth timber surfaces and edges  
C. Measuring moisture electrically  
D. Holding assemblies during glue-up  
**Correct answer:** B  
**Explanation:** Hand planes remove thin shavings under controlled conditions to develop accurate timber surfaces.  
**Traceability:** Lesson 5

**Q28.** Why is grain direction important when planing?  
A. Planing unfavourably against rising fibres can increase tear-out  
B. It changes the plane's metal composition  
C. It determines clamp capacity  
D. It only affects paint colour  
**Correct answer:** A  
**Explanation:** Reading fibre direction and adjusting technique can reduce lifting and tearing of timber fibres.  
**Traceability:** Lesson 5

**Q29.** A learner is preparing an edge that must be square to a reference face. Which method is best?  
A. Plane continuously without checking until the edge looks smooth  
B. Take controlled passes and check the edge repeatedly with an appropriate square against the reference face  
C. Measure only the board length  
D. Sand the edge until it appears straight  
**Correct answer:** B  
**Explanation:** Smoothness alone does not prove geometry. Frequent checking prevents excessive removal and helps maintain squareness.  
**Traceability:** Lesson 5

**Q30.** A plane begins producing deep tear-out. What should the carpenter do first?  
A. Push harder  
B. Stop and assess grain direction, cutting-edge condition, setup and depth of cut  
C. Strike the plane with a hammer  
D. Wet the timber regardless of material or specification  
**Correct answer:** B  
**Explanation:** Tear-out is a process signal. The cause should be diagnosed before additional material is unnecessarily removed.  
**Traceability:** Lesson 5

**Q31.** Why should the workpiece be securely supported during hand planing?  
A. To allow the worker to use both hands for controlled tool operation without the timber shifting  
B. To increase timber moisture  
C. To eliminate grain direction  
D. To make the plane heavier  
**Correct answer:** A  
**Explanation:** Stable workholding improves safety, control and surface accuracy.  
**Traceability:** Lesson 5

**Q32.** What is a sensible approach when planing end grain to reduce breakout at the far edge?  
A. Increase the depth of cut  
B. Use controlled light cuts and an appropriate support or technique that protects the far edge  
C. Remove all workholding  
D. Plane only with the blade retracted  
**Correct answer:** B  
**Explanation:** End grain can break away at unsupported edges. Light cuts and suitable support or working strategy reduce damage.  
**Traceability:** Lesson 5

**Q33.** A board has reached the required dimension but still has a small cosmetic irregularity. What should happen before more material is removed?  
A. Continue planing automatically  
B. Recheck the specification and decide whether further removal is permitted or necessary  
C. Reduce the board below tolerance to guarantee smoothness  
D. Ignore the required dimension  
**Correct answer:** B  
**Explanation:** Dimensional compliance takes priority over unnecessary material removal. Quality decisions must consider the full specification.  
**Traceability:** Lesson 5

### Lesson 6 — Hammers, Mallets, Screwdrivers & Fastening Tools

**Q34.** Why should the screwdriver tip match the screw recess correctly?  
A. To improve engagement, control and torque transfer while reducing damage to the screw and tool  
B. To change the screw length  
C. To avoid all need for pilot preparation  
D. To increase timber moisture  
**Correct answer:** A  
**Explanation:** A poorly matched driver can slip, damage the recess and reduce control.  
**Traceability:** Lesson 6

**Q35.** A screw repeatedly splits timber near the end of a narrow component. Which action is most appropriate?  
A. Use more force  
B. Review fastener size, edge/end distance and whether suitable pilot preparation is required for the material and fixing method  
C. Strike the screw with a hammer  
D. Ignore the split if the screw is tight  
**Correct answer:** B  
**Explanation:** Splitting indicates the fixing process or design needs correction, not additional force.  
**Traceability:** Lesson 6

**Q36.** Which tool is generally appropriate for controlled striking of a woodworking chisel designed for mallet use?  
A. A suitable woodworking mallet  
B. A measuring tape  
C. A marking gauge  
D. A try square  
**Correct answer:** A  
**Explanation:** A suitable mallet delivers controlled impact without treating precision tools as improvised striking equipment.  
**Traceability:** Lesson 6

**Q37.** Before using a hammer, what should be checked?  
A. Only whether the face is shiny  
B. Handle condition, secure head, striking-face condition and suitability for the task  
C. Whether it is the largest hammer available  
D. Whether another worker used it yesterday  
**Correct answer:** B  
**Explanation:** A loose head, damaged handle or unsuitable hammer can lead to loss of control and poor fastening quality.  
**Traceability:** Lesson 6

**Q38.** A nail starts bending during driving. What is the best response?  
A. Keep striking harder until it enters the timber  
B. Stop, assess the cause and correct or replace the fastener without damaging the workpiece  
C. Drive a second nail through the bent one  
D. Ignore it if the head is below the surface  
**Correct answer:** B  
**Explanation:** A bent fastener can damage the component and signals poor alignment, unsuitable fastener selection or another process problem.  
**Traceability:** Lesson 6

**Q39.** What is the best final check after installing a mechanical fastener?  
A. Confirm only that the tool was returned  
B. Inspect seating, alignment, surrounding material and whether the fixing meets the specification without avoidable damage  
C. Cover the fixing immediately so defects cannot be seen  
D. Tighten every screw as hard as possible  
**Correct answer:** B  
**Explanation:** Fastening quality includes the fastener, its seating, component condition and compliance with the required assembly.  
**Traceability:** Lesson 6

### Lesson 7 — Clamps, Vices & Safe Workholding

**Q40.** What is the main purpose of workholding during hand-tool operations?  
A. To stabilise the workpiece so the operation can be controlled safely and accurately  
B. To eliminate the need for tool inspection  
C. To make timber heavier  
D. To replace measuring tools  
**Correct answer:** A  
**Explanation:** Appropriate workholding prevents unwanted movement and allows controlled use of the tool.  
**Traceability:** Lesson 7

**Q41.** A clamp is tightened strongly on a finished timber surface and leaves a deep dent. What principle was neglected?  
A. Apply unlimited pressure  
B. Use appropriate clamp pressure and surface protection while maintaining alignment  
C. Always clamp directly on the most visible face  
D. Use the smallest contact area possible  
**Correct answer:** B  
**Explanation:** Excessive or concentrated pressure can damage the work. Pads or cauls and appropriate force may be required.  
**Traceability:** Lesson 7

**Q42.** Why should an assembly be checked for square while clamps are being tightened?  
A. Clamp pressure can shift or rack components out of alignment  
B. Squareness only matters after the adhesive has cured  
C. Clamps automatically guarantee square assemblies  
D. Checking square weakens the joint  
**Correct answer:** A  
**Explanation:** Tightening can move parts. Alignment should be monitored during the process, not only after it is fixed.  
**Traceability:** Lesson 7

**Q43.** A workpiece is clamped securely, but the clamp body lies directly in the planned saw path. What should happen?  
A. Saw through the clamp  
B. Reposition the workholding so the piece remains secure and the tool path is clear  
C. Remove all clamps and hold the piece by hand  
D. Start the cut from the opposite side without checking  
**Correct answer:** B  
**Explanation:** Workholding must provide stability without introducing a collision or obstruction in the tool path.  
**Traceability:** Lesson 7

**Q44.** Why is maximum clamp pressure not automatically best?  
A. Excessive force can distort components, damage surfaces or pull an assembly out of alignment  
B. High pressure always weakens metal clamps immediately  
C. Low pressure always creates stronger joints  
D. Clamp pressure has no effect on the workpiece  
**Correct answer:** A  
**Explanation:** The required pressure depends on the task, material, assembly and joining method; control is more important than brute force.  
**Traceability:** Lesson 7

**Q45.** A bench vice has damaged jaw faces and a loose mounting. What is the correct response?  
A. Use it only for small parts  
B. Remove or restrict it from use according to workplace procedure and report the defects for correction  
C. Tighten the workpiece more strongly  
D. Place cardboard under the bench and continue  
**Correct answer:** B  
**Explanation:** Workholding equipment itself must be stable and serviceable before it can safely secure a workpiece.  
**Traceability:** Lesson 7

**Q46.** During glue-up, one end of an assembly lifts as clamps are tightened. What is the best response?  
A. Continue tightening every clamp  
B. Stop and correct support, clamp position, pressure balance and alignment before the assembly sets  
C. Stand on the assembly  
D. Wait until the adhesive cures and then force it flat  
**Correct answer:** B  
**Explanation:** Clamp placement and balanced pressure should support the intended geometry; defects are easier to prevent than repair after curing.  
**Traceability:** Lesson 7

### Lesson 8 — Hand Tool Care, Sharpening, Storage & Inspection

**Q47.** Why does sharpness affect both quality and safe control of cutting tools?  
A. A serviceable sharp edge generally cuts more predictably with appropriate force, while a dull edge can encourage excessive force and poor results  
B. Sharp tools never require workholding  
C. Dull tools are always safer because they cannot cut  
D. Sharpness only affects appearance  
**Correct answer:** A  
**Explanation:** Correctly maintained edges support controlled cutting; maintenance does not remove the need for safe technique and workholding.  
**Traceability:** Lesson 8

**Q48.** What is the purpose of honing after appropriate sharpening preparation?  
A. To refine the cutting edge and remove very fine imperfections or burrs as part of the sharpening process  
B. To bend the cutting edge deliberately  
C. To replace the tool handle  
D. To increase clamp pressure  
**Correct answer:** A  
**Explanation:** Honing refines an already formed edge; the exact method depends on the tool and approved sharpening system.  
**Traceability:** Lesson 8

**Q49.** A tool is returned wet and covered in resin or dirt. Why is immediate basic care important?  
A. Contamination and moisture can interfere with inspection, operation and corrosion control  
B. Dirt permanently sharpens the edge  
C. Wet storage makes timber tools stronger  
D. Cleaning is only cosmetic  
**Correct answer:** A  
**Explanation:** Cleaning and drying support inspection, reliable operation and preservation of the tool.  
**Traceability:** Lesson 8

**Q50.** Which storage method best protects edged hand tools?  
A. Loose in a drawer where edges strike other tools  
B. In an organised dry location with cutting edges protected from contact and accidental handling  
C. On the floor beside the workbench  
D. Under timber offcuts  
**Correct answer:** B  
**Explanation:** Organised protected storage reduces edge damage, corrosion, accidental contact and lost tools.  
**Traceability:** Lesson 8

**Q51.** A chisel has severe edge damage that the learner has not been trained or authorised to repair. What should the learner do?  
A. Invent a sharpening method  
B. Remove it from service and refer it through the approved maintenance/reporting process  
C. Use it only on waste timber  
D. Strike it harder to reshape the edge  
**Correct answer:** B  
**Explanation:** Maintenance must remain within competence and workplace procedures. Unsafe or severely damaged tools should not be improvised back into service.  
**Traceability:** Lesson 8

**Q52.** Which end-of-task routine best represents professional tool care?  
A. Leave tools at the workpiece for the next person  
B. Clean → inspect → address/report defects within authority → protect cutting surfaces as appropriate → return tools to designated storage → leave work area orderly  
C. Store every tool without inspection  
D. Sharpen every tool whether required or not  
**Correct answer:** B  
**Explanation:** Professional care combines cleanliness, inspection, controlled maintenance, defect reporting, protection and organised storage.  
**Traceability:** Lesson 8

## Academic Quality Note

This summative bank intentionally integrates tool selection, measurement, cutting, chiselling, planing, fastening, workholding and maintenance decisions. It reflects the occupational principle that a competent carpenter does not merely identify a tool: the worker selects it for purpose, checks its condition, secures the work, uses the tool with controlled technique, verifies the result and leaves the tool/work area in a serviceable condition. South African woodworking curriculum material explicitly includes hand tools such as planes, saws, hammers, chisels, mallets, clamps, screwdrivers and measuring/marking tools, while relevant occupational standards include hand-tool use, care, maintenance and sharpening as embedded carpentry knowledge.
