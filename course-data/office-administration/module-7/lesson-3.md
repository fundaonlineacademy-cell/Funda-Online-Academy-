# Office Administration Certificate: From Admin to PA
## Module 7: Office Technology, Information & Confidentiality
### Lesson 3: Spreadsheets for Administrative Work

**Estimated study time:** 50 minutes

## Learning Outcomes
By the end of this lesson, you should be able to:
1. Use spreadsheets to organise routine administrative data.
2. Apply basic formulas, sorting, filtering and validation appropriately.
3. Design registers and trackers that are easy to maintain.
4. Reduce spreadsheet errors through structured quality checks.
5. Protect sensitive spreadsheet information and controlled versions.

## Why This Lesson Matters
Spreadsheets are useful for budgets, registers, action trackers, inventories and schedules, but they can also hide errors behind neat formatting. Administrators should understand how to structure data, use simple calculations and check results rather than treating spreadsheets as digital paper.

## Key Terms / Vocabulary
- **Cell** — Individual spreadsheet location identified by row and column.
- **Formula** — Expression calculating a result from data.
- **Function** — Built-in calculation such as SUM, COUNT or AVERAGE.
- **Filter** — Tool showing records matching selected criteria.
- **Data validation** — Rule restricting or checking permitted data entry.
- **Range** — Group of cells used together.

## Main Lesson Content
### 1. Design structured data
Use one clear header row and consistent columns. Each row should represent one logical record where possible. Avoid merging large areas or mixing unrelated data inside the same table.

### 2. Choose meaningful fields
A visitor register might contain Date, Visitor, Host, Arrival, Departure and Badge. An action tracker might contain Action, Owner, Due Date, Status and Follow-up. Fields should support the business process.

### 3. Use formulas instead of manual totals
For routine calculations, formulas reduce repeated arithmetic. However, verify that ranges include all intended rows and that numbers are stored correctly.

### 4. Sort and filter carefully
Sorting can reorder records, while filtering temporarily hides rows. Select the full data range to avoid separating one column from the rest of its record. Remember that filtered-out rows still exist.

### 5. Data validation
Drop-down lists for status or departments can improve consistency. Date and numeric rules can prevent some invalid entries. Validation supports quality but does not prove the underlying information is true.

### 6. Formatting for meaning
Use date, currency and percentage formats consistently. For South African financial examples, use rand formatting where appropriate. Avoid relying only on colour to communicate important status if users need other indicators as well.

### 7. Protect formulas and controlled areas
Where the system allows, protect formula cells or approved templates from accidental editing. Access protection should follow organisational policy and should not be treated as a substitute for proper security controls.

### 8. Quality checks
Check totals against source records, look for duplicate identifiers, missing values, unexpected dates and broken formulas. Use filters or exception columns to identify unusual records.

### 9. Version and collaboration control
Use approved shared files or systems rather than emailing many competing spreadsheet copies. Define who owns the authoritative workbook and how changes are reviewed.

### 10. Know spreadsheet limits
A spreadsheet is not always the right tool for complex databases, highly sensitive records or large multi-user workflows. Escalate when the process requires a more controlled system.

## Worked Example / Demonstration
An action tracker shows 24 tasks, but a SUM or COUNT formula only covers rows 2–20 after four new actions were added. The displayed total is therefore wrong. The administrator checks the range, corrects the formula and uses a structured table so future rows are included more reliably.

## Practical Activity
Create a 12-row administrative action tracker with columns for Action, Owner, Due Date, Priority, Status and Days Remaining. Add a status drop-down and one formula or function. Sort by Due Date and filter for incomplete high-priority actions. Then perform five quality checks.

## Knowledge Check
1. Why should each row normally represent one logical record?
2. What is a formula?
3. What risk occurs when sorting only one column of a data table?
4. What does data validation do?
5. Why should spreadsheet totals be checked against source data?
6. What does filtering do to hidden rows?
7. Why should many emailed spreadsheet copies be avoided?
8. When might a spreadsheet be the wrong tool?

## Key Takeaways
- Design spreadsheets as structured data, not loose visual layouts.
- Use formulas and validation with quality checks.
- Sorting and filtering require careful range control.
- Protect formulas and authoritative versions.
- Use stronger systems when spreadsheets no longer provide enough control.
