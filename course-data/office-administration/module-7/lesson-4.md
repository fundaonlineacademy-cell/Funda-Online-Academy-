# Office Administration Certificate: From Admin to PA
## Module 7: Office Technology, Information & Confidentiality
### Lesson 4: Presentations, PDFs & Shared Documents

**Estimated study time:** 45–50 minutes

## Learning Outcomes
By the end of this lesson, you should be able to:
1. Prepare clear presentation material for business use.
2. Convert and review documents in PDF format appropriately.
3. Use shared-document tools without creating version confusion.
4. Control comments, permissions and external sharing.
5. Select the right final format for the intended audience and purpose.

## Why This Lesson Matters
Administrative staff often prepare presentation decks, convert documents to PDF and share files with colleagues or clients. These tools make collaboration easier, but careless use can expose comments, outdated material or edit access that should never have been granted.

## Key Terms / Vocabulary
- **Presentation deck** — Ordered set of slides used to communicate information visually.
- **PDF** — Portable Document Format used to preserve document layout across systems.
- **Shared document** — File that authorised users access collaboratively through a digital platform.
- **Permission level** — Access such as View, Comment or Edit.
- **External sharing** — Granting file access to someone outside the organisation.
- **Link access** — Permission granted through a sharing link rather than individual account assignment.

## Main Lesson Content
### 1. Design presentations around the message
Each slide should have a clear purpose. Avoid filling slides with full paragraphs that presenters then read word for word. Use concise points, relevant data and simple visuals where they genuinely support understanding.

### 2. Keep presentation standards consistent
Apply approved branding, fonts, titles and layouts. Align headings and objects consistently. Check slide numbers, dates, names and figures just as carefully as in other business documents.

### 3. Use charts carefully
A chart should make a pattern easier to see. Check labels, units, dates and source data. Do not distort axes or visual scales in ways that mislead viewers.

### 4. PDF as a final distribution format
PDF can preserve layout and reduce accidental editing, but it is not automatically secure or final. Check whether comments, hidden pages, links or incorrect versions remain before distribution.

### 5. Shared-document collaboration
Shared documents can provide one current working copy. Use comments, suggestions or review workflows according to organisational practice rather than downloading and emailing numerous competing versions.

### 6. Permissions
Grant the least access necessary: some stakeholders only need View, reviewers may need Comment, and authors may need Edit. Avoid giving edit access simply because it is the default.

### 7. External sharing
Before sharing outside the organisation, verify the recipient, document classification, approval and sharing method. “Anyone with the link” settings may be inappropriate for sensitive business material.

### 8. Comments and hidden information
Internal reviewer comments can contain sensitive discussion. Resolve or remove them according to the approval process before creating the final external copy.

### 9. Version awareness
A shared file can still have an approval problem. The latest edited version may not be the approved release. Clearly distinguish working collaboration from final authorised output.

### 10. Final distribution check
Confirm recipient, access level, version, file format, links, permissions and any required expiry or withdrawal control. Test that external users can access only what they are intended to see.

## Worked Example / Demonstration
A PA prepares a client presentation in a shared workspace. Internal comments include pricing negotiation notes. Before sending the deck, the PA confirms approval, removes or resolves internal comments, exports the approved presentation to PDF, checks every slide, and shares only the final file through the authorised channel.

## Practical Activity
Prepare a five-slide management presentation with title, agenda, one data slide, one action slide and conclusion. Then create a distribution checklist comparing editable presentation, shared link and PDF. Decide which format is suitable for an internal reviewer and which for an external client.

## Knowledge Check
1. What should determine the content of each slide?
2. Why must chart labels and source data be checked?
3. Does PDF automatically make a document secure?
4. What is the advantage of one shared working copy?
5. Why should least-necessary permissions be used?
6. What risk can “anyone with the link” create?
7. Why should internal comments be reviewed before external distribution?
8. What should a final sharing check confirm?

## Feedback / Explanation
1. The communication purpose and audience need.
2. Incorrect labels or data can make a visually attractive chart misleading.
3. No. PDF preserves layout but permissions and content still need review.
4. It reduces competing edited versions during collaboration.
5. It limits unnecessary ability to change or redistribute information.
6. Sensitive information may reach unintended people if the link is forwarded.
7. Comments may reveal confidential discussion or unapproved information.
8. Recipient, version, format, permissions, links and appropriate access scope.

## Key Takeaways
- Presentations should communicate clearly rather than display excessive text.
- PDF is a format, not a guarantee of security or approval.
- Shared files reduce duplicates when permissions and ownership are controlled.
- Review comments and hidden information before release.
- Always verify external sharing settings.
